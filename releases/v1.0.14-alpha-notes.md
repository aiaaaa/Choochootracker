# ChooChooTracker v1.0.14-alpha — private test release

Not for public distribution yet. Validate Windows and PortMaster hardware before publishing.

## Highlights since v1.0.12-alpha

- Persistent 640×480 SDL composition canvas on native builds. Android/EGL no longer relies on retained window framebuffer contents, fixing disappearing tracker UI and corrupted title rendering. GPU rendering with VSync is used when render targets are available; software fallback is automatic.
- Graphics settings now expose the active renderer and a persisted **Waveform FPS** setting (`1`–`60`, default `30`). UI stays at 60 Hz while waveform generation is independently scheduled.
- Added the playback pixel piano and compact per-track Mixer peak meters.
- Improved the aChChid 303 workflow.
- PCM Sample instruments now support persisted slicing (`2`–`32` slices).
- Desktop key-jazz editing now supports Song, Chain and Project screens, including clipboard shortcuts and corrected deletion/cursor behavior.

## MIDI and PortMaster

- Reworked MIDI routing, MIDI In auditioning, MIDI Out note tracking/panic, Program/Bank state, generic CC FX, channel mapping, and device persistence.
- Added robust PortMaster MIDI support plus fixes for its audio-device selection, settings playback and key mapping.

## Fixes and polish

- Focused Settings submenus for Synths, Mixer and Graphics.
- Fixed Settings setup/draw callback regressions.
- Windows monitor waveform refresh now defaults to 30 Hz.
- Restored the title screen’s complete glyphs on Android by rendering its compact text bitmap without lossy GPU downsampling.

## Packages to validate

- Android APK and AAB (`arm64-v8a`, `armeabi-v7a`)
- Windows portable ZIP
- PortMaster ARM64 ZIP
- Web ZIP / `web/dist`

## Required private checks

- Windows: start, title screen, tracker editing, playback, MIDI input/output and waveform display.
- PortMaster: launch on hardware, controls, audio, playback settings and USB MIDI if available.
- Android: title, tracker, rotations, background/foreground and long editing session.
