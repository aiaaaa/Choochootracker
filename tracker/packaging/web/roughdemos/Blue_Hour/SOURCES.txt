REV 02 SOURCE / PROCESSING ADDENDUM
No new external recordings were downloaded. The break remains the self-recorded
RutgerMuller CC0 performance documented below; it is not the original Amen.

Drum derivatives: low-mid/snare-body EQ, parallel envelope compression, soft
saturation, 22.05 kHz resampling and 12-bit-style amplitude quantization stored in
PCM16. Common gain preserves relative hit dynamics. Main half-bar cuts are taken
from the processed two-bar atlas so the processing breathes across the phrase.
Onboard Aggro filtering provides an additional live shaping stage.

New original assets (all stereo, 22.05 kHz PCM16):
pad_glass_{m9,m11,maj7,sus4}.wav: captured from the user's existing Plaits 10 patch
using the current engine, with original FM/additive glass transient, stereo chorus,
soft filtering and amplitude quantization. Instruments 20-23 in A_Glass.
pad_strings_{m9,m11,maj7,sus4}.wav: original additive detuned string-ensemble
synthesis, stereo chorus and amplitude quantization. Instruments 20-23 in B_Strings.
pad_choir_{m9,m11,maj7,sus4}.wav: original harmonic/formant synthesis, stereo chorus
and amplitude quantization; no voice source. Instruments 20-23 in C_Choir.
Chord voicings follow the existing Plaits chord bank. The three banks are adjusted
to comparable sustained RMS, with headroom; no peak limiter is applied.
These newly generated audio assets are supplied under CC0 1.0.
Source code: tools/build_revision.py in the development project folder.
