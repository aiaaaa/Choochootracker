# roughdemos

Device song collection published with the owner's explicit approval on October
11, 2026. Includes 16 additional projects and a separately named snapshot of
Blue Hour's device Continue save. Eight byte-identical existing web examples
are omitted; Stock_Songs archival copies are not duplicated.

Five older sample-based projects were opened and saved by the current tracker
to embed their WAVs. All 37 newly embedded samples match the original PCM,
channels, sample rates and lengths. The same portable files replace those five
handheld saves, with hash-verified original backups on the device and Mac.
Already embedded archives and songs without external samples are unchanged.
`collection.json` records source/output hashes and embedded sample counts.
Existing Blue Hour and Low Water source notes are retained in their folders.

The web wrapper copies missing projects into /user/projects/roughdemos.
Existing user edits, settings, private presets and Continue are preserved.
This is a public starting collection, not automatic device/browser sync.
No private USER preset packs are included. Native app packaging is unchanged.
