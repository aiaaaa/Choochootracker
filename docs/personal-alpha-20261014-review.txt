What is actually new relative to the last personal daily
The alpha rolls up a much broader set of changes than this daily needs to add.
Sample slicing, MIDI, stereo/pan, native editors, master inserts, LSDj support,
Night and browser recovery were largely already in the personal baseline.
New in this integration: natural master reverb/delay tails after stop, desktop
Instrument-screen key jazz (PR #71 and Ctrl-release fix), Trance Gate,
continuous MME wave-pair morphing, the FXCell/16-bit command refactor and its
follow-up fixes, Raspberry Pi packaging and Android signing workflow updates.
Trance Gate and the FXCell refactor landed AFTER the release tag; this is the
alpha plus pinned post-release MAIN, not a reproduction of the release binary.
MME waveform morphing deliberately changes the sound of intermediate Waves
values; existing MME songs deserve an A/B listening pass. Monk uses a separate
voice implementation and retains its contextual MME command names.

Lane FX layout and compatibility review
- Visible structure remains three Phrase slots, four Table slots, three-letter
  names and byte-sized values. Sequencer/Track/active-engine groups and contextual
  insert controls remain. Personal SQ80 and Monk groups are retained.
- Structural layout becomes FXCell { uint16_t command; uint8_t value; }.
  Empty command is 0xffff; value FF remains a valid maximum.
- Phrase/Table, editor, clipboard, audio snapshot and motion-record command IDs
  now use the wider type. On-disk lane FX remain named commands plus byte values.
  This does not by itself add new visible commands or extra automation resolution.
- Existing personal command numbers, including SQ80, remain unchanged. There are
  254 allocated command positions; expansion past the old byte boundary is near.
- Finding fixed: mixed-column Phrase/Table paste still assigned FXCell indexed
  proxy objects. Implicit proxy copy assignment changes the temporary proxy,
  not the destination cell. All eight paste assignments now use command/value.
- Finding fixed: playback condition/table/row dispatch retained byte locals;
  a future high command could alias a low command such as PRO. Use FXId.
- Finding fixed: motion-destination API, native metadata and the help adapter
  retained byte IDs. These now preserve the full command width.
- Finding fixed: Phrase/Table display indexed fxNames without a range guard;
  unknown commands now display --- safely. Serializer already guards them.
- Personal SQ80 dispatch, editor availability, native chip harness and tests
  adapted to FXCell; legacy test adapters now map byte-empty to 0xffff.
- Upstream's temporary indexed FXCell compatibility layer remains. New code
  should use named fields; do not introduce proxy-to-proxy assignments.
