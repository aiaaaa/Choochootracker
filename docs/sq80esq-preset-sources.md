# SQ80/ESQ Rev2 preset sources

Reviewed October 13, 2026. Waveform banks are not part of these packages.

## Included FACTORY collections

- **Hybrid Starters:** twelve original parameter programs created for this
  integration, reproducibly generated by `tools/build_sq80_starters.py`.
  Uses standard wave IDs and demonstrates Wheel, Pedal, pressure, external
  modulation and glide. Distributed under the repository license.
- **Stuart Keith / TRIBEL:** unchanged `tribel.syx` from
  <https://github.com/stuartkeith/esq1>, commit
  `13a9fbccb8f43c4388e2280f250731c7e72dc08f`. The repository supplies this example
  under its MIT license. Copyright/license/source records accompany the ZIP
  and are also in `tracker/packaging/common/licenses/sq80esq/`.

## Research leads, not bundled

- <https://squest.com/Products/MidiQuest13/Instruments/EnsoniqSQ80/index.html>
  describes 2,331 public-domain sounds in its product's Patch Zone. A directly
  obtainable, independently redistributable SysEx collection was not established.
- <https://www.donsolaris.com/?tag=sq80> lists a free 4,500-patch collection.
  Search discovery succeeded; direct access was denied. Redistribution terms
  were not established.
- <https://ericmorello.com/ensoniq-esq-1-patches/> links multiple collections,
  including 117 banks, but the page supplies no explicit redistribution license.

These leads may be useful for personal USER imports; no contents from them or
from the owner's existing private collection were added to FACTORY. The included
MIT example is one preset, not a newly discovered large open bank.
